# Джарвис — голосовой ассистент для ПК 🎙️

Говорите «Джарвис, открой ютуб» — и он открывает. Понимает русскую речь,
отвечает голосом, умеет управлять компьютером, а на свободные вопросы
отвечает через нейросеть Claude.

## Возможности

- 🕐 «Джарвис, который час?» / «какое сегодня число?»
- 🌐 «открой ютуб / гугл / браузер / вконтакте / гитхаб»
- 🖥️ «открой калькулятор / блокнот / проводник / терминал»
- 🔍 «найди рецепт борща» — поиск в Google
- 📸 «сделай скриншот» — снимок экрана в домашнюю папку
- ⏲️ «таймер на 5 минут» — напомнит голосом
- 🔌 «выключи компьютер» — с голосовым подтверждением
- 💬 Живое общение как в фильме: «Привет, Джарвис!» — «К вашим услугам, сэр.»
- 🧠 Любой другой вопрос — ответит нейросеть (нужен API-ключ, см. ниже)

## Установка на Windows — один клик

1. Установите [Python 3.10+](https://www.python.org/downloads/) — при установке
   отметьте галочку **Add Python to PATH**.
2. Двойной клик по **`start.bat`** — при первом запуске Джарвис сам
   установит всё, что ему нужно, и запустится. Говорите: «Привет, Джарвис!»

Если автоустановка не сработала — запустите `install.bat` и попробуйте снова.
На Linux / macOS: `bash install.sh`, затем `python3 jarvis.py`.

## Как пользоваться

- Начинайте фразу со слова **«Джарвис»**: «Джарвис, открой ютуб».
- Или скажите просто «Джарвис» — он ответит «Слушаю» и будет ждать команду.
- Для выхода: «Джарвис, выход» (или Ctrl+C).

### Режимы запуска

| Команда | Режим |
|---|---|
| `python jarvis.py` | голосовой (нужен микрофон) |
| `python jarvis.py --text` | текстовый: печатаете команды с клавиатуры |
| `python jarvis.py --no-wake` | реагирует на любую фразу, без слова «Джарвис» |

## Нейросеть для свободных вопросов (опционально)

Чтобы Джарвис отвечал на любые вопросы («что такое чёрная дыра?»),
нужен ключ Claude API:

1. Получите ключ на [console.anthropic.com](https://console.anthropic.com/).
2. Задайте переменную окружения перед запуском:

   ```
   # Windows (постоянно):
   setx ANTHROPIC_API_KEY "ваш-ключ"

   # Linux / macOS:
   export ANTHROPIC_API_KEY="ваш-ключ"
   ```

Без ключа Джарвис работает только со встроенными командами.

## Примечания

- Распознавание речи использует бесплатный сервис Google — нужен интернет.
- Озвучка работает офлайн через системные голоса Windows
  (русский голос «Irina» встроен в Windows 10/11).
- Свои сайты и программы легко добавить в словари `SITES` и `APPS`
  в файле `commands.py`.
